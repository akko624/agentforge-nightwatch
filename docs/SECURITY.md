# 安全边界

上传 Skill 是不可信数据。API 与静态 Worker 只解码、解析和匹配文本 / AST；不得执行、import、shell 调用或运行上传脚本。正常容器加固不是恶意代码沙箱，Compose 不启用动态执行。

## 导入边界

ZIP 检查路径、设备名、重复路径、Unicode 归一化、条目类型及符号链接；限制上传大小、文件数量、单文件大小、总解压大小、层级和压缩比。对象只能写入平台控制的存储根，不接收用户目标目录。安全 YAML 不执行自定义 tag，嵌套与输入大小受限。

默认限制：上传 20 MiB、总解压 100 MiB、单文件 10 MiB、300 条目、10 层、100:1 压缩比。流式请求层另限 multipart 开销；ZIP 实际读取量与声明尺寸交叉校验。危险导入在持久化 Skill 版本前拒绝。细节与攻击回归见 `INGEST.md`。

## 运行与凭据

API / Worker 使用非 root 用户、只读根文件系统、删除 Linux capabilities、禁止提权和受限 tmpfs。它们不挂载 Docker socket、宿主 HOME、生产凭据或敏感目录。Compose 端口绑定 loopback；数据库与队列没有公开端口。

动态 Runner 必须在独立可信执行环境中实现，先验证隔离能力，再运行白名单测试 profile。没有适用的 gVisor / microVM 或无法落实权限时返回 `UNAVAILABLE` / `UNSUPPORTED`。不得使用本机 subprocess 或普通 Docker 容器替代。

## 报告与日志

finding 证据应截断和脱敏，报告中的疑似 secret 不保留原值。前端渲染使用 React 文本转义，不将上传 Markdown 直接作为 HTML 注入。全局日志不记录源代码正文、令牌、模型密钥或原始异常载荷。对象仓库包含原始上传数据，仍需管理员控制文件系统访问、备份与保留期限。

原始 ZIP 和文件内容 hash 属于敏感工件溯源数据；不通过报告提供源文件下载接口。S007 的 finding 指纹使用固定脱敏证据，不从完整 secret 原值生成可枚举指纹。证据脱敏是最佳努力，不能代替禁止上传生产数据的操作约束。

`start-local.ps1` 仅修改子进程所需的当前进程环境，结束时恢复调用者环境；不修改用户级环境、代理或应用配置。`stop-local.ps1` 核对记录 PID、真实命令行、创建时间与当前工作区后停止；Windows 虚拟环境 launcher 的直接 Python 子进程还须同命令行且创建不早于父进程，才会先被停止。脚本不终止 console host / 无关后代，不使用端口杀进程，也不删除持久数据。

## MVP 限制

静态规则为 best effort，有误报与漏报；不会证明整个 Skill 安全。没有真实认证 / RBAC / 多租户，不能公开承载多人互不信任的服务。语义、动态和模型宿主效果评测未配置；报告必须显示真实覆盖与未完成原因。生产部署还需认证、网络访问控制、配额、审计与备份等独立审查。
