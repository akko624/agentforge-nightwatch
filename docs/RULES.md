# 内置静态规则

`rules/builtin-rules.yaml` 是平台自定义的 SQSP-S001–SQSP-S016 规则目录，版本 `1.0`；内置引擎版本 `0.1.0`。它们不是 OWASP 官方规则编号。实现只读取上传内容并使用标准库 AST / 文本解析，绝不执行、import 或调用其中的代码。

| 规则 | 实际证据与限制 |
|---|---|
| S001 | Python 已知凭据来源 → 本地赋值传播 → 已知网络调用；或 shell 上传参数含敏感路径。需要证据链；单独出现 URL 不触发 CRITICAL。最多 3 轮局部传播，不提供完整数据流证明。 |
| S002 | curl/wget 下载 pipe 到 shell，包括显式反斜杠续行；可能是合法安装，必须审核。 |
| S003 | Python AST 识别 eval/exec、os.system/popen、subprocess shell=True，支持 import alias；注释和纯字符串不作为调用。 |
| S004 | 不支持的二进制、嵌套归档或编码，产生发现并将静态覆盖标为 PARTIAL。 |
| S005 | 明确中英文高优先级指令覆盖、系统提示泄露候选，不等于完整语义注入检测。 |
| S006 | 敏感凭据目录和工作区外路径文本候选，注释/反面教材标记低置信。 |
| S007 | 已知 token / PEM 标识与高熵凭据赋值。证据使用固定脱敏文本，fingerprint 不派生自 secret 原值。 |
| S008 | 含执行/遵循远程指令语境、缺少固定 commit/hash 的 URL；普通参考链接不触发。 |
| S009 | 网络 deny（包括缺省最低权限）与已知 Python / shell / JavaScript 出站调用候选冲突；只提供静态证据，未声称动态阻断。 |
| S010 | input/sys.argv/os.environ → 本地赋值 → open 写模式或 Path.write 路径；低置信，仍需人工核对路径验证。 |
| S011 | 未锁定/可变版本、无法解析依赖声明。记录依赖覆盖不足；没有查询漏洞库，绝不生成虚构 CVE。 |
| S012 | package.json 非空安装生命周期 hook；setup.py 中命令执行候选。 |
| S013 | 删除、覆盖、发送邮件等高影响动作缺确认语句/声明。文本候选，不代替执行层授权。 |
| S014 | 宽路径、secret_access、宽 shell 工具声明启发式；低置信，任务必要性由人审核。 |
| S015 | 外部工具说明缺少可识别的失败/超时处理；维护性建议。 |
| S016 | 缺少 eval cases、许可证或版本；覆盖与维护性提示。 |

对注释和明确反面教材标注 `context_note`、降低置信度；不会把研究文档的候选直接称为已确认恶意。检测范围包括隐藏文本、嵌套 Markdown、脚本和依赖声明；二进制/嵌套压缩包不会被继续解压或执行。

Python AST 最大输入 2 MiB、节点数 50,000；单次扫描最多保留 2,000 条候选。解析失败或超过限制返回 `PARTIAL` 与原因，不能伪装为没有问题。任意编码混淆、动态 import、跨文件/跨函数复杂数据流、所有编程语言的真实执行语义仍是盲区。依赖漏洞、语义分析和动态沙箱需要独立可信适配器。
