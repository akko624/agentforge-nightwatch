# AgentForge NightWatch 当前能力范围

AgentForge NightWatch 当前是一个 **Skill ZIP 质量与安全验证平台**，不是通用 Agent 工程平台。这里的 Skill 是供 Agent 按宿主规则调用的技能包，包根目录必须包含 `SKILL.md`；完整 Agent 项目、运行时和多 Agent 编排不在当前导入范围内。

已支持的 Skill 流程是：**安全读取 ZIP → 规范/静态检查 → 证据报告 → 版本比较 → 改进建议**。上传内容不会被执行、导入、安装或作为命令调用。

## 当前与路线

| 工件类型 | 当前状态 | 已有能力 | 后续能力 |
|---|---|---|---|
| Skill ZIP（含 `SKILL.md`） | 已支持 | 安全解包、规范/静态扫描、质量覆盖、版本比较、公开聚合报告、改进简报 | 受控候选补丁、隔离真实评测 |
| Agent 工作流 | 路线图 | 不接收、不解析、不执行 | 节点/权限图、依赖与工具链策略 |
| 提示包与知识资产 | 路线图 | 不接收、不解析 | 注入防护、版本/来源追踪、评测集 |
| MCP/连接器配置 | 路线图 | 不接收、不解析 | 权限最小化、网络边界、密钥引用审计 |

## 当前可用的改进闭环

```text
已测工件 -> 证据与覆盖 -> 改进简报 -> 人/Agent 提出候选版本
  -> 安全导入新版本 -> 重新扫描与版本比较 -> 人工批准发布
```

当前“Skill 改进工作台”已经根据扫描报告生成 P0/P1/P2 建议，并导出 Markdown 简报。它不会修改原 ZIP、执行待测代码或伪造模型建议。候选版本由人或获授权的 Agent 在外部工作区创建，随后作为新的 Skill ZIP 重新进入平台；这让每次优化都有可比较的证据链。

未来的“补丁审阅台”只能生成候选 diff，并必须经过静态复检、版本比较与人工确认才能写回。动态/真实宿主评测仍必须在获批准的、可回收的隔离环境中进行。
