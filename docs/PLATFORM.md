# AgentForge NightWatch 平台说明

AgentForge NightWatch 是一个 **Skill ZIP 质量与安全验证平台**。这里的 Skill 是供 Agent 按宿主规则调用的技能包，包根目录包含 `SKILL.md`。

平台工作流：**安全读取 ZIP → 规范/静态检查 → 证据报告 → 版本比较 → 改进建议**。上传内容始终按数据解析，扫描过程不会执行、导入、安装或调用包内代码。

## 已实现能力

| 对象 | 已有能力 |
|---|---|
| Skill ZIP（含 `SKILL.md`） | 安全解包、规范/静态扫描、质量覆盖、版本比较、公开聚合报告、改进简报 |

## 当前可用的改进闭环

```text
已测工件 -> 证据与覆盖 -> 改进简报 -> 人/Agent 提出候选版本
  -> 安全导入新版本 -> 重新扫描与版本比较 -> 人工批准发布
```

当前“Skill 改进工作台”已经根据扫描报告生成 P0/P1/P2 建议，并导出 Markdown 简报。它不会修改原 ZIP、执行待测代码或伪造模型建议。候选版本由人或获授权的 Agent 在外部工作区创建，随后作为新的 Skill ZIP 重新进入平台；这让每次优化都有可比较的证据链。
