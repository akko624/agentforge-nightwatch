# AgentForge NightWatch 平台定位

AgentForge NightWatch 是个人 Agent 工程平台，不是单一的 Skill 检查页。它解决的是同一个工程问题：**任何进入 Agent 生态的工件，都需要可追溯的摄入、可解释的证据、明确的发布门禁和可验证的下一轮改进。**

## 当前与路线

| 工件类型 | 当前状态 | 已有能力 | 后续能力 |
|---|---|---|---|
| Agent Skill ZIP | 已支持 | 安全解包、规范/静态扫描、质量覆盖、版本比较、公开聚合报告、改进简报 | 受控候选补丁、隔离真实评测 |
| Agent 工作流 | 路线图 | 不接收、不解析、不执行 | 节点/权限图、依赖与工具链策略 |
| 提示包与知识资产 | 路线图 | 不接收、不解析 | 注入防护、版本/来源追踪、评测集 |
| MCP/连接器配置 | 路线图 | 不接收、不解析 | 权限最小化、网络边界、密钥引用审计 |

## 自演进的可信闭环

```text
已测工件 -> 证据与覆盖 -> 改进简报 -> 人/Agent 提出候选版本
  -> 安全导入新版本 -> 重新扫描与版本比较 -> 人工批准发布
```

当前“Skill 改进工作台”已经根据扫描报告生成 P0/P1/P2 建议，并导出 Markdown 简报。它不会修改原 ZIP、执行待测代码或伪造模型建议。候选版本由人或获授权的 Agent 在外部工作区创建，随后作为新版本重新进入平台；这让每次优化都有可比较的证据链。

未来的“补丁审阅台”只能生成候选 diff，并必须经过静态复检、版本比较与人工确认才能写回。动态/真实宿主评测仍必须在获批准的、可回收的隔离环境中进行。
